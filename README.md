## 🚀 Running Locally

No dependencies required! Just plain HTML5, CSS3, and modern JavaScript.

1. Clone the repository:
   ```bash
   git clone https://github.com/Soumy-WebWizard/PerfectWeatherService.git
   cd PerfectWeatherService
   ```

2. Open `index.html` directly in your browser, or start a local server:
   ```powershell
   # Using PowerShell
   powershell -ExecutionPolicy Bypass -File server.ps1
   ```
   Visit `http://localhost:8088/` in your browser.
